# Open Your Beauty E-Commerce Website

Your website is running at: **http://localhost:8000**

## How to Open:

### Option 1: Command Palette
1. Press `Ctrl+Shift+P` (or `Cmd+Shift+P` on Mac)
2. Type: **Simple Browser: Show**
3. Enter URL: **http://localhost:8000**

### Option 2: Terminal
Run this command:
```bash
echo "Open http://localhost:8000 in Simple Browser"
```
